## 3. 정량 목표 제안 기준

일반 품질 속성(예: 정확성, 사용성, 접근성)은 이 추적표의 비기능 요구사항 연결에서 제외했다. 고객 요구사항에 수치가 없지만 수용 여부 판단에 정량 목표가 필요한 항목만 아래와 같이 일반 목표를 제안한다.

| 대상 | 제안 목표 | 적용 조건 | 확정 전 확인 사항 |
| --- | --- | --- | --- |
| 물품 신규 등록 | 습득 학생 또는 행정 담당자가 등록을 시작한 시점부터 저장 완료까지 2분 이내 | 등록 유형별 필수 필드와 입력 흐름이 확정된 뒤 측정 | 사용자별 현재 기준선, 실제 필수 입력 항목, 등록 후 검토 절차 |
| 조회 응답 시간 | 조회 요청의 95%가 3초 이내 완료 | 일반적인 교내 서비스 이용 부하 | 동시 사용자 수, 물품 데이터 규모, 네트워크 환경 |
| 등록 저장 응답 시간 | 저장 요청의 95%가 3초 이내 완료 | 일반적인 교내 서비스 이용 부하 | 동시 사용자 수, 데이터 검증 범위, 네트워크 환경 |
| 가용성 | 서비스 운영 시간 중 월간 가용률 99% 이상 | 운영 시간과 계획 점검 시간을 별도로 정의 | 실제 운영 시간, 점검 정책, 장애 대응·복구 체계 |
