# 교내 분실물 관리 서비스 실행 가이드

## 로컬 실행

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
uvicorn app.main:app --reload
```

- 사용자 화면: `http://127.0.0.1:8000`
- API 명세: `http://127.0.0.1:8000/docs`

## 제공 기능

- 분실물과 습득물 게시물 등록
- 물건명·설명·카테고리 기반 검색
- 분실/습득 유형 및 보관 상태별 필터 API
- 관리자 토큰을 이용한 상태 변경 (`X-Admin-Token` 헤더)

## 운영 전 설정

`.env.example`을 참고해 `DATABASE_URL`과 `ADMIN_TOKEN`을 안전한 값으로 설정하세요. 현재 구현은 개발용 SQLite 구성이므로, 배포 시 PostgreSQL과 인증 체계를 연결하는 것을 권장합니다.
